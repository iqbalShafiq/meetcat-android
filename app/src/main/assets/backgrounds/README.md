# 🖼️ Background Assets

Taruh file **background images/videos** di folder ini.

## Format yang Didukung
- **Images**: `.jpg`, `.jpeg`, `.png`, `.webp`
- **Videos**: `.mp4`, `.mov`, `.avi`

## Contoh Files
```
bg_gradient_purple.jpg
bg_gradient_blue.jpg
bg_pattern_dots.png
bg_space_stars.mp4
bg_nature_forest.mp4
```

## Rekomendasi
- **Resolusi**: 1920x1080 (Full HD) atau 1280x720 (HD)
- **Ukuran**: < 5MB per file
- **Format**: JPG untuk static, MP4 untuk animated

## Cara Menambahkan
1. Copy file ke folder ini
2. Nama file akan otomatis di-format (e.g., `bg_gradient_purple.jpg` → "Bg Gradient Purple")
3. Rebuild project untuk melihat perubahan

Lihat guide lengkap: `/VIDEO_EDITOR_ASSETS_GUIDE.md`

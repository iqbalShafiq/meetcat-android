# 🎵 Sound/Audio Assets

Taruh file **audio/music/sound effects** di folder ini.

## Format yang Didukung
- **Audio**: `.mp3`, `.wav`, `.m4a`, `.ogg`

## Contoh Files
```
background_music_chill.mp3
background_music_upbeat.mp3
meow_cute.mp3
purr_soft.mp3
cat_meow_happy.wav
```

## Rekomendasi
- **Format**: MP3 (best compatibility)
- **Bitrate**: 128kbps - 320kbps
- **Durasi**:
  - Sound effects: 1-5 detik
  - Background music: 30 detik - 3 menit
- **Ukuran**: < 3MB per file

## Sumber Royalty-Free Music

- [YouTube Audio Library](https://www.youtube.com/audiolibrary) ⭐ Recommended
- [Free Music Archive](https://freemusicarchive.org)

### Sound Effects
- [Freesound.org](https://freesound.org) - Search: "cat meow", "purr"
- [Zapsplat](https://www.zapsplat.com)
- [Mixkit](https://mixkit.co/free-sound-effects/)

## ⚠️ Legal Notice
Pastikan semua audio files:
- **Royalty-free** atau punya license
- Credit creator jika diperlukan
- **Tidak copyrighted**

## Cara Menambahkan
1. Download audio dari sumber royalty-free
2. Copy file ke folder ini
3. Nama file akan otomatis di-format (e.g., `background_music_chill.mp3` → "Background Music Chill")
4. Rebuild project untuk melihat perubahan

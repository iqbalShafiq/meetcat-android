# 🐱 Cat Objects (GIF/Video Transparan)

Taruh file **cat GIFs/videos** di folder ini.

## ⚠️ PENTING
File harus **TRANSPARAN** atau **sudah dihapus backgroundnya**!

## Format yang Didukung
- **GIF**: `.gif`
- **Video**: `.mp4`, `.mov` (dengan alpha channel)

## Contoh Files
```
dancing_cat.gif
jumping_cat.gif
sleeping_cat.gif
running_cat.mp4
playing_cat.gif
```

## Rekomendasi
- **Resolusi**: 512x512 atau 1024x1024
- **Background**: Harus transparan!
- **Ukuran**: < 2MB per file
- **Loop**: Sebaiknya looping seamless

## Cara Mendapatkan Cat GIF Transparan

### Option 1: Download dari situs
- [GIPHY](https://giphy.com) - Filter by "transparent" atau "stickers"
- [Tenor](https://tenor.com) - Cari "transparent cat"

### Option 2: Hapus background sendiri
- [Remove.bg](https://www.remove.bg) - Upload GIF/image, download hasil transparan
- [Unscreen.com](https://www.unscreen.com) - Hapus background dari video/GIF

## Cara Menambahkan
1. Copy file ke folder ini
2. Pastikan file benar-benar transparan (cek dengan preview)
3. Rebuild project untuk melihat perubahan

Lihat guide lengkap: `/VIDEO_EDITOR_ASSETS_GUIDE.md`
